## 09:41:18 fix(startup): 接管启动图时序，消除冷启动首页整体闪屏

- 现象：冷启动时首页"整体闪一下"，像是全界面刷新了一次
- 根因（模拟器 android-35 + release APK 录屏逐帧取背景色实证）：
  1. `expo-splash-screen` 在 Android 的默认退场动画是**全屏 alpha 淡出 400ms**
     （`SplashScreenManager.configureSplashScreen` + `SplashScreenOptions.duration=400`），
     这层不透明遮罩盖在已渲染好的首页上再褪掉 —— 实测深色模式下可见
     `#FCED9A → #EEE094 → #C4B67A → #7C7553 → #2C2D1D` 的整屏渐变
  2. 应用原本没调 `preventAutoHideAsync`，隐藏启动图的是 expo-router
     （`global-state/store.js onReady → rAF → internalMaybeHideAsync`），
     "导航就绪"不等于"首页有内容"，慢设备上还会露出空窗
  3. `app.json` 的 splash 配置没有 `dark` 变体，生成的
     `values-night/colors.xml` 为空，深色模式下启动图仍是亮黄 `#FFEE9D`
- 修复：
  - 新增 `src/src/services/splash.ts`：`initSplashScreen()`（模块顶层调用）
    设 `setOptions({duration: 0})` + `preventAutoHideAsync()` 接管隐藏权，
    并挂 5s 兜底超时（超时记 warn 后强制隐藏，避免初始化异常时卡死在启动图）；
    `hideSplashScreen()` 幂等
  - `src/src/app/_layout.tsx`：新增 `contentReady`（锁存水合 + 首次便签加载完成），
    就绪或进入崩溃屏时才撤走启动图；`refreshAsync()` 包 try/finally，
    失败也放行（原先抛错会连带跳过后台同步注册与每日备份）
  - `src/app.json`：`expo-splash-screen` 增加 `dark.backgroundColor: #1a1c1e`（= `DARK_SHELL.background`）
- 验证（API 35 模拟器 release 包）：
  - 浅色冷启动背景色 `#FCED9A → #FBFAFD` **无中间过渡帧**；深色模式启动图与应用背景同色，无亮黄闪屏
  - PIN 冷启动（启动图 → 锁屏）同样无过渡帧，解锁后首页直接带 12 条数据
  - logcat 无 `[splash] content not ready` / `failed to take over splash screen`
  - tsc / expo lint / jest 134 例全通过
