# 变更记录 2026-10-05

## 2026-10-05 14:57 真机反馈修复（cleartext/PIN 性能与交互/顶栏统一）

- Android 允许明文流量：app.json 经 expo-build-properties 设置 `usesCleartextTraffic: true`（局域网 HTTP WebDAV 需要；下次 prebuild/run:android 重新生成 manifest 后生效）
- PIN 锁定默认时间 0（立即）→ 10 分钟，选项新增"10 分钟"
- PIN 哈希由 PBKDF2（3 万次迭代）改为随机盐 + 单次 SHA-256（毫秒级）：便签正文未加密，PIN 仅为 UI 级隐私锁，无需慢哈希；验证按记录的 iterations 字段兼容旧 PIN，修改 PIN 后自动切换新算法
- PIN 输入框自动聚焦：Modal 内 autoFocus 不可靠，改为弹层打开后延迟 300ms 手动聚焦；支持回车跳下一框、末框回车提交；锁屏输入框同样处理
- 首页顶部图标与编辑页工具栏图标统一为 40dp 圆形点击区域（含按压反馈），图标 22dp 对齐；首页自定义顶栏与编辑页工具栏高度固定 56dp 与 Stack AppBar 一致
- 设置页启用 Stack AppBar（标题"设置" + 系统返回键），与其他页面导航统一
- typecheck/lint/jest（37/37）通过
