### 数据层（src/src/data/）
- `theme.ts`：经典 7 色主题色板常量（与桌面端色值严格一致）+ 便签标题/预览提取。
- `db.ts`：expo-sqlite 初始化（WAL）、user_version 迁移脚本、轻量 KV 存储。
- `noteRepository.ts`：便签 CRUD、软删除/恢复/彻底删除、**下行条件更新守卫**（单事务批量应用，快照后本地编辑则跳过）。
- `note.ts`：Note 实体、协议要求格式的时间戳生成（ISO-8601 UTC 七位小数）、expo-crypto UUID v4。

### 同步协议层（src/src/sync/）
- `dto.ts`：Schema v1 严格序列化/防御性解析、LWW 毫秒比较、防乒乓业务比较、换行符规范化。
- `crypto/sigv4.ts`：最小 SigV4 签名器（@noble/hashes，对照桌面端 SigV4Signer.cs 翻译）。
- `backends/`：WebDAV（PROPFIND/GET/PUT/DELETE/MKCOL 自举，fast-xml-parser 解析 207）与 Cloudflare R2/S3（path-style + SigV4，ListObjectsV2 分页）双实现 + IStorageBackend 抽象。
- `engine.ts`：全量对账引擎（单飞信号量、全失败熔断、LWW 裁决、墓碑传播、下行守卫），对照桌面端 SyncEngine.cs 逐条对齐。
- `scheduler.ts` / `settings.ts` / `syncRunner.ts`：expo-background-task 周期同步注册（≥15 分钟）、同步设置持久化（非敏感部分）、前台/防抖/后台统一同步入口。
